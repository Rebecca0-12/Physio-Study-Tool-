# Physio Study Tool

[view live demo} (https://sensory-motor-physiology.netlify.app)

A browser-based study tool built to make reviewing Sensory & Motor Physiology faster and easier.

## Features

This project combines three study tools into a single page:

- Study Summary – A structured summary covering the eye, auditory system, general sensory physiology, the cerebellum, and the motor system.
- Flashcards – 100 interactive flashcards with flip animations, shuffle mode, and previous/next navigation.
- Practice Quiz – 100 multiple-choice questions with instant feedback, score tracking, and the option to retry only the questions answered incorrectly.

## Why I Built It

I built this a few hours before a physiology exam because I was struggling to study from long lecture slides. Reading wasn't the problem—I needed a better way to remember what I'd read.

So I turned the material into a single-page study tool with organized notes, flashcards, and practice questions that made it much easier to review and test myself under time pressure. I'm sharing it in case it helps other students studying the same topics.

## Tech Stack

- HTML
- CSS
- JavaScript

Everything runs entirely in the browser with no frameworks, build tools, or backend.

## Topics Covered

- Functional anatomy of the eye
- Retina and its layers
- Visual pathway and visual pathway lesions
- Auditory physiology and hearing tests
- General sensory physiology
- Cerebellar function
- Motor system physiology
